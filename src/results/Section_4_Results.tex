
\section{Results}
This section reports how stylistic prompt features affect model outputs across five domains. We quantify three effects per variant relative to a paraphrase-neutral reference: (i) semantic drift via BERTScore F1, higher is closer to neutral; (ii) sentiment polarity shift via TextBlob, higher is more positive; and (iii) word length change, indicating verbosity shifts. We present aggregated, per-domain results in the main text. Full per-prompt, per-domain breakdowns appear in the Appendix.
